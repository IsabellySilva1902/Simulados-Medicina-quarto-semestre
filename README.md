# Simulados — Quarto Semestre

Simulados interativos de múltipla escolha, estilo ENAMED/residência, um por disciplina. Cada pasta contém um `index.html` autocontido (sem backend, sem build step), pronto para GitHub Pages.

## Disciplinas

- [`farmacologia-clinica/`](farmacologia-clinica/) — 220 questões, 7 assuntos
- [`genetica-medica/`](genetica-medica/) — 150 questões, 5 assuntos
- [`saude-mental/`](saude-mental/) — 220 questões, 7 assuntos
- [`clinica-cirurgica/`](clinica-cirurgica/) — 217 questões, 7 assuntos

## Funcionalidades (todas as disciplinas)

- Amostragem balanceada por assunto e anti-repetição entre tentativas (localStorage)
- Embaralhamento de alternativas a cada tentativa, com código de sessão opcional para reproduzir o mesmo conjunto de questões entre colegas
- Modos Exame e Tutor, dica, marcação para revisão, riscar alternativa
- Autosave e retomada de simulado em andamento
- Resultados com desempenho por assunto, retentativas (erradas/marcadas/pontos fracos)
- Revisão detalhada com filtros, histórico de tentativas, cobertura do banco de questões
- Export/import de progresso e exportação de resultados como página imprimível
- Modo escuro
